# 女装小红书独立 Agent｜中文说明书

## 包含的两个 Agent

### 小红书商品图审图

职责是把权威产品参考图、产品事实卡和待审生成图逐张对照。它检查服装结构、颜色、面料表观、人物与肢体完整性、文字水印、第三方标识、构图可读性和整组六图的重复度。

它只输出：

- `A`：可以进入人工审核；
- `B`：需要一次定向返工；
- `C`：严重失真，或第二次仍失败，应停止自动返工。

每张图应返回 `ordinal`、`grade`、`issues`、`targeted_retry_prompt`。它不生图、不写文案、不审批、不发布。

首次调用示例：

```text
请调用“小红书商品图审图”独立审核这 6 张候选图。权威产品参考图在【路径】，产品事实卡在【路径】，候选图目录是【路径】。逐张输出 A/B/C、可见位置、与事实的具体差异和一次性定向返工提示；不要生成图片或发布。
```

### 小红书事实型文案

职责是根据事实卡的 `verified` 字段、员工明确提供的卖点，以及六张 A 图中可谨慎描述的场景，写小红书标题、正文、标签和 `used_facts`。

它不会补造纤维比例、价格、优惠、库存、销量、产地、发货、显瘦效果、客户反馈或护理承诺，也不审批、不发布。

首次调用示例：

```text
请调用“小红书事实型文案”为这款女装写一版小红书文案。事实卡在【路径】，六张 A 图在【路径】，员工确认卖点是【内容】。输出 title、body、tags、used_facts；unknowns 不得写成事实，不要发布。
```

## 安装位置与刷新

默认安装到：

```text
~/.codex/agents/xiaohongshu-product-image-reviewer.toml
~/.codex/agents/xiaohongshu-fact-copywriter.toml
```

如果设置了 `CODEX_HOME`，则安装到该目录下的 `agents/`。安装完成后运行：

```bash
python3 scripts/install_agents.py --check
```

两个结果都为 `ok` 才算本地安装完成。Codex 已打开时，建议新开一个对话刷新 Agent 列表。

## 与编排 Skill 的关系

`xhs-fashion-qc-publish` 负责流程顺序和门禁；这两个 Agent 分别负责独立审图和事实型文案。安装 Agent 不会自动安装编排 Skill、图像生成能力、RedBeacon、飞书、Ego 或任何账号登录态。
